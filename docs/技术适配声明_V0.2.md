# 顺期健身app 技术适配声明 V0.2

基线：PRD V0.3 + 现有交付包 +《AI Agent 产品上线部署手册》《AI 产品 Vibe Coding 通用技术栈手册》。
范围：Web MVP 的 P0 闭环；不包含真实支付、多设备账号体系、消息推送或生产云发布。

## 架构结论

- 前端：Next.js 15 + React 19 + TypeScript + Tailwind CSS v4。
- 后端：FastAPI + Pydantic v2 + SQLAlchemy 2。
- 数据：当前使用 SQLite；已有数据库通过幂等列升级兼容。本地升级只是交付包兼容层，生产环境应切 PostgreSQL + Alembic。
- AI：结构化训练规则和安全验证不依赖模型。模型只可润色非敏感调整原因、处理受限教练对话；无 Key 自动降级。
- 会话：建档时生成随机设备令牌，只保存 SHA-256 摘要；浏览器持有 30 天 HttpOnly/SameSite Cookie。接口按会话校验资源归属。

## 关键纠偏

1. 日记不再发送给 DeepSeek，也不再自动分析情绪。情绪来源固定为用户五档手动选择。
2. 激素使用者不推断自然周期；不规律周期只给宽泛区间；自然周期至少两个完整间隔才显示日历阶段。
3. 周期标签不再自动增量训练，只作为解释背景。显式疼痛、睡眠、酸痛、压力、症状和出血优先。
4. 计划验证器新增经验等级、器械、今天时长、重复动作与时长一致性检查；教练换动作同样不可绕过。
5. 兜底计划继续走同一动作/器械/伤病过滤；无可用动作时返回恢复方案。
6. 置信度只统计用户真实主动填写字段和既往反馈，不再因默认值自动变成 1.0。
7. 导出与删除补齐周期记录、日记/备注、安全事件和逐组训练记录。

## 数据边界

- 可发送给教练：训练目标、经验、器械、今日结构化状态、当前计划、低精度周期背景。
- 永不进入模型提示词：日记原文、备注原文、精确经期日期、访问令牌。
- 未授权情绪：请求中的情绪按 ok 处理，不保存日记或情绪记录。
- 撤回可选授权：立即停止处理；历史数据保留以便导出，直至用户单独删除或全量删除。

## 上线前硬门槛

1. PostgreSQL + Alembic 正式迁移；去掉 SQLite 兼容升级作为主迁移方式。
2. 加入邀请制或正式账号恢复、多设备登录、Cookie Secure、CSRF 防护、速率限制。
3. 引入 Sentry/结构化日志/trace_id，但日志禁止写日记、周期日期和令牌。
4. 对动作库、安全阈值和舒适文案进行运动科学与医学边界评审并冻结版本。
5. 补 Playwright 关键旅程和前端组件测试；当前验证为 TypeScript、生产构建、后端 29 项自动化测试和 HTTP 冒烟。
6. 使用真实模型 Key 做一次受控冒烟并检查成本、超时和脱敏；本轮未调用真实付费模型。
