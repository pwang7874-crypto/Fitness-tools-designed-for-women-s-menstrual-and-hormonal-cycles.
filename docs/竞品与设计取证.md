# 顺期健身app 竞品与设计取证

更新时间：2026-08-27
目的：记录本轮优化的公开证据、许可边界与落地映射。本文区分“来源事实”“产品推断”和“本项目设计决策”。

## 设计系统

### Refero · Ease Health

- 来源事实：Refero 的 [Ease Health 风格页](https://styles.refero.design/style/e9f5e976-53f7-42f5-a882-4e63b3c2f734) 将该风格描述为奶油纸张上的临床植物系，给出 Forest Ink、Sage Mist、Keylime Wash、Slate Hush 等色值、衬线/无衬线配对、14px 圆角、无阴影、色块分层和双栏 Hero 等设计规范。
- 产品推断：相比高饱和运动品牌或深色数据仪表盘，这套风格更适合顺期健身app的“可信但不冰冷、健康但不医疗化”定位。
- 本项目决策：直接采用 Refero 公布的设计 tokens 和组件语言，重新实现为 Tailwind v4/CSS；没有复制 Ease 官网图片、商标、文字或业务代码。
- 落地位置：frontend/app/globals.css、frontend/components/ui.tsx、frontend/components/Nav.tsx。

## GitHub 产品参考

### workout.cool（MIT）

- 来源：[Snouzy/workout-cool](https://github.com/Snouzy/workout-cool)
- 来源事实：开源训练平台包含动作目录、动作详情、训练计划和进度记录。
- 本项目决策：动作库增加检索、部位/难度/居家筛选；计划与教练替换始终引用审核动作 ID。
- 复用边界：未复制其组件、动作数据或视频资源。

### Ephira（MIT）

- 来源：[adulbrich/ephira](https://github.com/adulbrich/ephira)
- 来源事实：隐私优先的经期记录产品，覆盖流量、症状、情绪、药物/避孕与备注，并强调本地保护、可关闭预测和完整导出。
- 本项目决策：周期/情绪授权拆开；完整导出包含周期、日记和安全事件；激素模式仅记录出血；不足两个完整间隔不显示具体阶段。
- 复用边界：未复制其应用代码或加密实现。

### GymCoach（MIT）

- 来源：[Julien-Au/gymcoach](https://github.com/Julien-Au/gymcoach)
- 来源事实：训练教练基于结构化训练上下文工作，计划变更先预览再保存，并提供离线训练记录思路。
- 本项目决策：增加“教练会看到什么”；日记和精确日期明确排除；AI 修改先经过器械/等级/伤病/时长校验，再由用户确认应用；训练支持逐组与部分完成。
- 复用边界：未复制其鉴权、离线同步或 UI 源码。

### training-app（无许可证）

- 来源：[aleksandar-todorovic-dev/training-app](https://github.com/aleksandar-todorovic-dev/training-app)
- 来源事实：仓库未提供允许复用的开源许可证。
- 可学习概念：逐组引导、显式完成、部分训练和“退出不等于完成”。
- 复用边界：无许可证意味着未复制任何代码、样式或文本，只把公开产品行为作为需求研究材料。

### Ovumcy（AGPL-3.0）

- 来源：[ovumcy/ovumcy-web](https://github.com/ovumcy/ovumcy-web)
- 来源事实：隐私优先、自托管的周期跟踪产品，提供 CSV/JSON 导出，并明确预测不是医疗或避孕依据。
- 可学习概念：不规律周期降低预测可靠度、明确免责声明、可迁移数据。
- 复用边界：本项目没有采用 AGPL 源码；否则会产生相应的网络分发开源义务。

## 落地映射

| 外部优秀点 | 顺期健身app 落地 |
|---|---|
| 结构化动作目录 | 搜索、筛选、肌群/器械/难度标签、站外教学入口 |
| 逐组训练 | 开始时间、逐组勾选、组间计时、部分完成、停止原因 |
| AI 上下文透明 | 展示使用字段和永不发送字段 |
| 修改先预览 | 对话变更预览 → 确定性验证 → 用户应用 → 新计划版本 |
| 周期预测可降级 | 自然/激素/不规律/未启用四模式 |
| 隐私数据可迁移 | 完整 JSON 导出、单篇日记/单条周期删除、全量删除 |
| 样本阈值 | 少于 8 条情绪记录不展示分布性洞察 |

## 许可结论

本轮提交没有引入第三方源码文件、图片、字体文件、动作数据集或视频文件。实现均在现有技术栈内独立完成；公开项目用于产品取证，Refero 公布的设计系统 tokens 用于视觉实现并保留来源说明。
