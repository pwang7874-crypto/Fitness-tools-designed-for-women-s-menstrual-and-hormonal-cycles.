# 顺期健身app 前端技术适配声明 V0.2

## 视觉选择

采用 Refero 的 Ease Health“临床植物温室”设计系统：

- 主色 #0f3e17 Forest Ink；页面 #fffefc Cream Paper。
- Keylime #e1f4df、Sage #b1dbb8、Slate #b6ced5 作为分层表面。
- 中文宋体/衬线展示标题 + Inter/系统无衬线正文。
- 卡片、按钮统一 14px；标签使用全圆角。
- 不使用卡片阴影，层级由色块、间距和排版表达。
- 桌面最大内容宽度 1200px；移动端固定底部导航。

设计来源和许可边界见《竞品与设计取证》。

## 页面与状态

- /onboarding：三步建档；必要授权与可选敏感授权分离。
- /：结构化打卡 → 安全拦截/计划 → 逐组执行 → 反馈；AI 调整带上下文披露、预览和确认。
- /cycle：月历、记录增删、四种周期模式的不同结果。
- /diary：只展示手动情绪与私密原文，支持单篇原文删除。
- /library：搜索、部位、难度、居家筛选。
- /insights：7/28 天统计、事实观察、情绪样本进度与最低 8 条阈值。
- /profile：编辑训练档案、撤回授权、数据清单、导出和确认式全量删除。

所有页面覆盖 loading、empty、error、success 或 disabled 中的适用状态；401 会清理失效的本地 profile_id 并回到建档入口。

## 交互动效

独立 CSS 实现，无新增运行时依赖：

- 页面和卡片 reveal/panel-in。
- 列表 stagger。
- 按钮 hover/press 微位移。
- 逐组完成 check-pop。
- 准备度圆环过渡、情绪分布条过渡、加载呼吸点。
- details 展开图标旋转。
- 全部动效受 prefers-reduced-motion 控制。

## 可访问性与响应式

- 交互控件最小高度 40–44px；表单均有可见标签。
- Chip 使用 aria-pressed；开关使用 role=switch；导航使用 aria-current。
- 错误使用 role=alert；训练/教练动态区域使用 aria-live。
- 键盘焦点统一 3px 可见轮廓。
- 颜色不作为唯一信息编码，状态同时有文字。
- 桌面顶部导航；移动端六项底部导航；主要双栏布局在窄屏自动单栏。

## 工程约束

- API 类型集中在 frontend/lib/api.ts，页面无 any。
- 所有请求同源并携带 HttpOnly 会话 Cookie。
- 错误信息统一提取 FastAPI detail，不向用户暴露堆栈。
- 当前 bundle 不引入图表库、动效库或状态库，避免 MVP 依赖膨胀。
